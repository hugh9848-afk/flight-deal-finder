# 친구와 함께 사용하기

결과 화면은 https://hugh9848-afk.github.io/flight-deal-finder/ 에서 함께 볼 수 있습니다.
친구에게는 이 주소만 보내면 됩니다. 화면을 열거나 필터를 바꿔도 항공 API 호출이 추가되지 않습니다.
API 키는 결과 화면에 입력하지 않습니다.

## 친구 계정 연결

SerpApi 사용자 ID나 로그인 토큰이 아니라 **API Key**가 필요합니다.
친구가 공동 사용에 제공한 별도 계정의 키를 사용합니다. 같은 계정의 키를 두 번 입력한다고 한도가 늘어나지는 않습니다.

1. 로컬 프로젝트 `.env`에 `SERPAPI_API_KEY_FRIEND=친구의키`를 추가합니다. 두 번째 친구는 **다른 이름**인 `SERPAPI_API_KEY_FRIEND_2=두번째친구의키`를 추가합니다. 기존 `SERPAPI_API_KEY`는 유지합니다. 같은 이름을 여러 줄 쓰지 않습니다.
2. `node src/cli.js quota`로 등록한 계정들의 연결과 남은 횟수를 확인합니다. 이 명령은 항공권을 검색하거나 알림을 보내지 않습니다.
3. GitHub 저장소 Settings → Secrets and variables → Actions → New repository secret에서 같은 이름 **SERPAPI_API_KEY_FRIEND**으로 키를 등록합니다. 두 번째 친구는 **SERPAPI_API_KEY_FRIEND_2**라는 별도 Secret으로 등록합니다.
   로컬 `.env` 변경만으로 GitHub 자동 실행에 전달되지는 않습니다.
4. 코드를 한 번에 커밋·푸시합니다. 현재 워크플로우는 코드 푸시 시 스캔·배포를 실행합니다.

GitHub Secrets 설정: https://github.com/hugh9848-afk/flight-deal-finder/settings/secrets/actions

## 예산

본인과 친구 두 명이 **공용 검색 한 번과 같은 결과 화면**을 사용합니다. 사람별 검색·할당량은 없으며, 세 계정 전체에서 한 회차 최대 51회를 사용합니다. 남은 횟수가 있는 계정을 자동으로 골라 같은 검색 작업을 이어갑니다. 계정별 장부는 실제 API 한도를 지키기 위한 내부 기록입니다.

| 항목 | 키 하나 | 서로 다른 키 둘 | 서로 다른 키 셋 |
|---|---:|---:|---:|
| 각 계정이 무료 250회인 경우의 요금제 합계 | 250회 | 500회 | 750회 |
| 앱 자체 월 상한 (계정당 200회) | 200회 | 400회 | 600회 |
| 한 회차 검색 상한 | 19회 | 35회 | 51회 |
| 발굴 | 7회 | 7회 | 7회 |
| 상세 | 12회, 최대 6개 일정 | 28회, 최대 14개 일정 | 44회, 최대 22개 일정 |

250회가 기존 계정으로 이전되는 방식이 아닙니다. 계정마다 실제 남은 횟수를 확인하고, 잔여량이 더 넉넉한 계정에 작업을 배정합니다.
출국편과 귀국편은 같은 계정으로 조회합니다. 각 계정에 1회씩만 남았으면 이를 합쳐 왕복 한 건을 조회하지 않습니다.
계정 확인에 실패한 키는 사용하지 않으며, 다른 계정은 계속 사용할 수 있습니다.
외부에서 같은 계정을 사용하거나 무료 한도가 변경되면 앱이 쓸 수 있는 횟수도 줄어듭니다.

기존과 같은 안전 여유를 유지하려고 계정마다 월 200회 상한을 적용합니다. `SERPAPI_MONTHLY_BUDGET`은 합계가 아니라 **계정당** 상한입니다.
`SERPAPI_RUN_BUDGET`을 비우면 위 표처럼 자동 설정됩니다. GitHub Variables나 `.env`에 19가 남아 있으면 여러 키를 넣어도 회차 상한은 19입니다.
두 계정으로 31일 달의 정기 실행 11회를 모두 돌면 최대 385회, 세 계정은 최대 561회이며, 중간 코드 푸시·수동 실행도 월 한도에 포함됩니다.

장부는 `data/serpapi-ledger.json`, `data/serpapi-ledger-friend.json`, `data/serpapi-ledger-friend2.json`으로 분리합니다. 장부에는 키나 이메일을 저장하지 않습니다.
실패나 캐시 응답도 앱 장부에서는 보수적으로 한 번 예약한 것으로 세므로, 대시보드보다 앱 사용량이 클 수 있습니다.

API 키를 README, 공개 파일, 이슈 또는 채팅에 적지 마세요. 친구 키를 제거하려면 `.env`와 GitHub Secret에서 해당 항목만 삭제하면 됩니다.

참고: [SerpApi Account API](https://serpapi.com/account-api)는 계정별 한도·잔여량을 반환하며, 계정 조회 자체는 검색 한도를 사용하지 않습니다.
