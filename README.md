# 인천 출발 특가 탐색기

인천공항(ICN)에서 출발하는 **유럽 · 아프리카 · 조지아 · 몽골** 방향 10~20일 일정 항공권 중,
단순 최저가가 아니라 **평소 운임보다 비정상적으로 싼 것**을 찾아 알려줍니다.

## 지금 무엇이 되고 무엇이 안 되나

**되는 것**
- 넓게 훑기 → 실제 조회 → 가격 확정, 3단계 깔때기 전체 흐름
- 가격 이력 쌓기(글자 파일), 이력이 없어도 판정하는 하이브리드 특가 판정
- 여행가치 점수(가격·이동시간·경유·위험·수하물·실제 체류일)
- 오픈조 생성과 도시 간 육로 이동비 **추정**
- 지역별 경유 제한: 유럽·조지아·몽골은 1회까지, 아프리카는 2회까지 (`settings.maxStopsByRegion`)
- 중복 특가 묶기, 재알림 억제
- 안드로이드/맥에서 볼 수 있는 모바일 화면
- 시험 22개 전부 통과 (`npm test`)

**아직 안 되는 것 / 주의**
- **Travelpayouts 토큰이 있어야 진짜 데이터가 나옵니다.** 토큰 없이는 연습용 가짜 데이터만 돕니다.
- Travelpayouts 는 **참고가(캐시)만** 줍니다. 이동시간·수하물·환불규정이 응답에 없어 전부 '미확인'으로 남고,
  이 공급자만으로는 **확정 특가가 만들어지지 않습니다.** 실제 조회·가격확정 공급자(Duffel 등)를 붙여야 완성됩니다.
- Amadeus 자기가입 포털은 2026-07-17 폐쇄되었습니다. `amadeus` 어댑터는 기업 계약이 있을 때만 쓸 수 있습니다.
- 도시 간 육로 이동비는 실제 요금 조회가 아니라 **거리로 짐작한 추정치**입니다. 화면에 '추정' 딱지가 붙습니다.
- 자동 카카오톡 알림은 연결되어 있지 않습니다. 요약문 파일과 웹훅까지만 됩니다.

## 시작하기

### 1. 키 없이 바로 시험해보기
```bash
npm test
node src/cli.js scan --provider=mock --regions=europe
```

### 2. 진짜 데이터 연결하기 (넓게 훑기)
1. https://www.travelpayouts.com 에서 무료 가입
2. 대시보드에서 **API 토큰**과 **마커(marker)** 복사
3. `.env.example` 을 `.env` 로 복사해 붙여넣기
```bash
cp .env.example .env
node src/cli.js scan --provider=travelpayouts --regions=europe,caucasus
```

### 3. 실제 조회·가격 확정 붙이기 (미구현)
Travelpayouts 는 참고가만 줍니다. 확정 특가를 만들려면
`capabilities.live` 와 `capabilities.confirm` 이 true 인 공급자를 하나 더 붙여야 합니다.
`src/providers/base.js` 의 약속만 지키면 나머지 코드는 그대로 동작합니다.

### 4. 자동 실행 (서버 없이, 컴퓨터가 꺼져 있어도)
1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소 Settings → Secrets and variables → Actions 에서 추가:
   - `TRAVELPAYOUTS_TOKEN`
   - `TRAVELPAYOUTS_MARKER`
   - (선택) `NOTIFY_WEBHOOK_URL`
3. Settings → Pages → Source 를 **GitHub Actions** 로 설정합니다.
4. 3일마다 자동 실행되고, 결과가 공개 주소에 올라갑니다. Actions 탭에서 손으로도 돌릴 수 있습니다.

**API 키는 GitHub 금고에만 저장되고 공개 사이트에는 결과 JSON만 올라갑니다.**

## 구조

```
src/
  config/       목적지 공항 95곳, 검색 규칙(경유 횟수·날짜 범위·판정 기준)
  core/         공통 양식지, 날짜 조합, 특가 판정, 여행가치 점수, 중복 제거
  providers/    데이터 공급자 어댑터 (travelpayouts / amadeus / mock / ground)
  store/        가격 이력, 알림 기록
  pipeline/     3단계 깔때기, 결과 저장
  notify/       요약문·웹훅
web/            안드로이드에서 볼 화면 (GitHub Pages 로 공개)
data/history/   가격 이력 (글자 파일, 저장소에 함께 보관)
```

공급자를 바꾸려면 `src/providers/base.js` 의 약속만 지키는 클래스를 새로 만들고
`src/cli.js` 의 `makeProvider` 에 한 줄 추가하면 됩니다.

## 경유 횟수 정책

인천발 유럽은 직항이 드물어 **경유 1회를 빼면 후보가 거의 없습니다.**
아프리카 남부·서부(케이프타운·빈트후크·다카르 등)는 1회 경유 조합 자체가 거의 없어 2회까지 열어둡니다.

단, 경유가 늘어나면 여행가치 점수의 **이동시간·경유대기 항목이 자동으로 깎입니다.**
그래서 2회 경유 노선은 값이 확실히 쌀 때만 상위에 올라옵니다.

## 지켜지는 원칙

- 참고가(캐시)와 조회가, 확정가를 화면에서 **색으로 구분**합니다.
- 조회 화면과 확정 화면의 값이 다르면 **확정 특가로 내보내지 않고** '확인 필요'로 보냅니다. (시험으로 보장)
- 확인하지 못한 항목은 만들어내지 않고 `unknown` 목록에 남깁니다.
- 육로 이동비 등 추정한 값에는 항상 `estimated` 표시가 붙습니다.
- 비공식 스크래핑 도구를 데이터원으로 쓰지 않습니다.
